# THE LAST SIGNAL: Game Design Document

Living document. Update it as decisions are made.

## Pitch
A cooperative survival horror game for Roblox.

## Design pillars
- **Solo and multiplayer both work.** The game must be playable and scary with one player or several.
- **Two camera modes.** First person and third person are both supported.
- **Multiple distinct creatures.** Each creature has its own behaviour and can be added without changing core code.

## Open questions
These are undecided and should be answered before the related systems are built.
- Setting and story: what is "the signal"?
- Win and lose conditions for a round
- Target number of players per server
- Survival mechanics (resources, items, tools)
- Creature roster and the rules each one follows
- Which camera mode is the default
